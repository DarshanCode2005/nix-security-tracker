# Contributing Guide

This repository contains the source code for the NixOS Security Tracker. The contributing guidelines have been split into several focused documents to help you find what you need quickly:

- [**Overview & Hacking**](docs/overview.md): General repository guidance and an introduction to the tech stack.
- [**Onboarding & Local Setup**](docs/onboarding.md): Instructions for Nix shells, credentials, database setup, and running the service locally or in a container.
- [**Code Organization & Best Practices**](docs/code_organization.md): Hints relevant during active development, including formatting rules, architecture, styling, and `pgpubsub` listener patterns.

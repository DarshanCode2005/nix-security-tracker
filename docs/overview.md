# Overview and Hacking

This document is for anyone wanting to contribute to the implementation of the security tracker.

This repository contains the source code for the NixOS Security Tracker.
While this document outlines general contributing information, the other directories in this repository have additional `README.md` files with more specific information relevant to their sibling files.
